# Hessam Shahbazi GitHub Pages Site

This is a static personal resources page inspired by the visual structure of the memQ resources page. It is ready for GitHub Pages and does not require a build step.

## Files

- `index.html` - page structure and content
- `styles.css` - responsive layout, dark visual design, and card artwork
- `script.js` - mobile navigation, active section highlighting, and the animated hero network

## Upload to GitHub Pages

1. Open the `hessamshahbazi.github.io` repository on GitHub.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository root.
3. In repository settings, open **Pages** and publish from the main branch root if it is not already enabled.
4. Visit `https://hessamshahbazi.github.io/` after GitHub finishes deploying.

## Quick Edits

- Update email links by searching for `hshahb4@uic.edu`.
- Update publication cards in the `Selected Resources` section of `index.html`.
- Update social links in the `Let’s Connect` section of `index.html`.
