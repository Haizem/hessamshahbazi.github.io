# Hessam Shahbazi Quantum Portfolio

This is a static GitHub Pages portfolio for quantum materials, quantum transport, computational chemistry, and energy applications. It is inspired by the visual structure of the memQ resources page and does not require a build step.

## Files

- `index.html` - page structure, CV-based content, news, industry experience, and publication links
- `styles.css` - responsive layout, quantum visual theme, cards, news, and industry sections
- `script.js` - mobile navigation, active section highlighting, and animated hero network

## Upload to GitHub Pages

1. Open the `hessamshahbazi.github.io` repository on GitHub.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository root.
3. In repository settings, open **Pages** and publish from the main branch root if it is not already enabled.
4. Visit `https://hessamshahbazi.github.io/` after GitHub finishes deploying.

## Quick Edits

- Update email links by searching for `hshahb4@uic.edu`.
- Update publication cards in the `Featured Work` and `Selected publications` sections of `index.html`.
- Update news cards in the `News and Interviews` section.
- Update social links in the `Let's Connect` section of `index.html`.
